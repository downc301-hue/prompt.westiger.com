# AI美女提示词生成器

只需选择，就能自动生成结构完整的中文提示词。生成后复制粘贴到 **豆包** 即可生成高质量写实AI美女图片。无需 API Key、无需注册、完全免费。

## ✨ 主要功能

### 1. 提示词生成器（index.html）

通过下拉选择的方式，自动拼装出结构严谨、上下文一致的中文提示词：

- **场景预设**：32 种精选场景（夏日窗边、夜晚卧室、月光房间、清晨和室、户外蓝墙、正午海滩、夜间泳池、雨天车站、夏日祭典 等）
- **人物设定**：肤质妆容、发色、发型、身材、气质、表情、脸部展示方式、小饰品 8 个维度自由组合
- **脸部展示方式**：正常露脸 / 口罩遮脸 / 手机遮脸（镜面自拍）/ 脸部在画框外（第一人称 POV）
- **角色固定（参考图）**：支持上传图片保持人脸特征或发型发饰，实现同一人物多场景生成
- **画质方向**：标准高清 / 手机随手拍（防 AI 感更强）
- **构图控制**：取景范围（中近景/上半身/全身/特写）、镜头视角（手机俯拍/平视50mm/仰拍/自拍/长焦/远景）
- **结构化输出**：提示词按「主题 → 拍摄动机 → 人物 → 服装姿势 → 背景光线 → 构图 → 质感 → 负面排除」的结构组织，避免描述矛盾

### 2. 投稿文案生成器（post.html）

图片生成后，为你的 X（原Twitter）账号自动生成投稿文案：

- **角色设定**：名字、年龄、职业、性格、说话风格、兴趣、开号动机、粉丝距离感 —— 共 8 项
- **本地保存**：角色设定保存在浏览器 localStorage，多账号一键切换
- **投稿类型**：日常汇报型 / 烦恼咨询型 / 故事叙述型 / 随机混合
- **结尾方式**：提问结尾（互动率高）/ 余韵结尾
- **字数控制**：短（~80字）/ 中（~140字）/ 长（数行叙述）
- **输出提示词**：复制后粘贴给豆包，上传图片可进一步提高文案精准度

## 🎯 使用流程

### 文生图（从零生成）

1. 打开 [https://prompt.westiger.com](https://prompt.westiger.com)
2. 选择场景、人物、服装、姿势、构图等参数
3. 点击 **「生成提示词」** → 点击 **「复制」**
4. 粘贴到豆包对话框发送
5. 如不满意，点击 **「🎲 随机全部」** 重新生成

### 图生图（固定角色）

1. 先用文生图流程，生成一张满意的「母版图」
2. 在「2.5 角色固定」区域选择参考模式（**保持人脸** / **保持发型**）
3. 每次生成新图时，把「母版图」作为参考图上传给豆包
4. 只需修改场景、服装等参数，就能得到同一人物的不同场景照片

> 💡 **防劣化技巧**：每次只用同一张母版图做参考。用生成图再当参考迭代最多 2 次，迭代越多噪声越多。角色崩了就从零重新生成。

### 投稿文案

1. 打开 [post.html](https://prompt.westiger.com/post.html)
2. 填写角色设定（名字、职业、性格等）→ 点击 **「💾 保存当前设定」**
3. 选择图片对应的场景、投稿类型、结尾方式
4. 点击 **「生成投稿文案提示词」** → 复制
5. 粘贴给豆包，**同时上传你生成的图片**
6. 豆包会输出 3 条不同风格的投稿文案，选一条发布即可

## 🛡️ 防拦截技巧

- 直接重新发送一次（很多是误判）
- 把表情或服装调温和一点
- 换个场景或拍摄动机
- 避免自己手动添加强调身体部位的词
